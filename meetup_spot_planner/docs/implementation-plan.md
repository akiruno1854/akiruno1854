# 実装計画（骨格優先）

## フェーズ0: 骨格作成
- ディレクトリのみ先行作成（app/domain/infra/tests/data）
- バックエンドとフロントエンドの接続確認
- `GET /api/health` 実装

## フェーズ1: 最小機能の縦切り
- `POST /api/search` 実装（fixtureデータのみ）
- フィルタリング（距離・カテゴリ・営業時間）
- スコアリング（ルールベース）
- 地図ピン + ランキング表示

## フェーズ2: 外部連携
- Google Maps等の取得アダプタ導入
- 正規化・重複排除を導入
- API失敗時のフォールバック（fixture）

## フェーズ3: 品質強化
- キャッシュ導入
- ログ計測（レスポンス時間、候補数、フォールバック率）
- テスト拡充（統合/E2E）

## フェーズ4: 拡張準備
- 予約可否データ連携を抽象化
- ユーザー報告の入力口を追加可能なAPI設計へ拡張
- スコア説明可能性（根拠表示）を改善
